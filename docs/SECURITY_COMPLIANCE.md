# SECURITY_COMPLIANCE（泛用框架）

## 1. 密钥管理
- 密钥仅存储在服务端环境变量或密钥管理服务。
- 前端与客户端禁止接触供应商密钥。
- 轮换周期：建议 30~90 天，泄露后立即吊销并替换。

## 2. 审计与追溯
- 每次报告生成记录：模型版本、策略版本、工具调用、证据来源、成本延迟。
- 审计日志保留：至少 180 天（按合规要求调整）。
- 高风险操作（配置发布/权限变更）必须留审计记录。

## 3. 权限控制
- 最小权限原则：按角色隔离策略配置、数据读取、运维操作。
- 生产环境写操作需审批或受控流程。
- API 鉴权采用 token/JWT，服务间通信使用专用凭证。

## 4. 合规提示
- 产品定位为投研辅助，不构成投资建议。
- UI 必须显示风险提示与非收益承诺声明。
- 对外数据与日志处理遵循数据使用协议与当地法规。

## 5. 后续补充
- 明确具体适用法规（地区化）。
- 明确日志脱敏策略与字段级访问控制。
