# RUNBOOK（泛用框架）

## 1. 值班与分级
- P0：核心链路不可用（生成报告失败率持续高）
- P1：性能退化或部分功能不可用
- P2：非核心问题

## 2. 日常操作
- 启动：`docker compose up -d` -> `uvicorn app.main:app --reload --port 8000`
- 健康检查：`GET /health`
- 数据库初始化：`psql "$DATABASE_URL" -f sql/001_init.sql`

## 3. 故障处理流程
1. 识别：确认告警指标与影响范围。
2. 缓解：触发降级策略（关闭高成本路径、限制 tier）。
3. 定位：检查 tool trace、错误码、上游依赖状态。
4. 恢复：逐步恢复功能并观察指标回归。
5. 复盘：记录根因、影响、修复项。

## 4. 降级策略
- 数据源超时：回退最近快照并标记 `DEGRADED`。
- 模型不可用：切换到备用模型或规则输出。
- 成本超额：降低 tier 调用深度与工具次数。

## 5. 成本守门
- 预算指标：每请求成本、每 tier 成本、日成本总额。
- 阈值动作：超过阈值自动降级并告警。
